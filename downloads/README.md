# Pi installation archive

[Download rated-rip-pi.zip](https://github.com/briandal107/rated_rip/raw/refs/heads/main/downloads/rated-rip-pi.zip)
for version 0.4.0. Follow the [first-boot guide](../docs/FIRST_BOOT.md).

The ZIP contains the Python application, bundled vocal model, documentation and
fast tests under a `rated_rip/` directory. Install its dependencies on the Pi as
described in the guide. Raspberry Pi OS is installed separately using Imager.

The MP3 fixtures, rendered previews, virtual environment and build outputs are
excluded. The ZIP needs no OLA installation and adds no automatic startup service.
